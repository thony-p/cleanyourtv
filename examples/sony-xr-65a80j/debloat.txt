# Notes on this firmware:
# - Home: launcherx has priority 2 and the setup wizard's RecoveryActivity has priority 1, so setupwraith
#   is in this list (batch 6). With it disabled, build-and-install.sh set Home on the first try and it
#   survives reboots. Re-enable it before a factory reset (restore.sh does).
# - /data is small (16 GB storage, 4 GB for /data on the sibling X80J). The first launcher install can fail
#   with "Requested internal only, but not enough space"; `tools/tv.py 'pm trim-caches 1G'` frees ~450 MB.
# - `svc power reboot` is killed on this firmware; use `adb reboot` (and check `uptime`).
# - The Sony tab on the Google TV home stays as a label after sonytab is disabled; it only goes with launcherx.
# - Applied in batches with reboots and checks after each (Home, Settings, inputs, Media Player, no crashes).
#   If something breaks, `pm enable <package>` and please report it.
