# Sony BRAVIA XR-65A80J (BRAVIA 4K VH2, MediaTek MT5895), EU firmware
# Google TV 12 (API 31), build BRAVIA_VH2_EU-user 12 STT2.230505.001.S136 682241 release-keys.
# 32-bit only (ro.product.cpu.abilist = armeabi-v7a,armeabi), so sideloaded apps need the armeabi-v7a build.
# 256 packages, 6 already disabled at the factory.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/sony-xr-65a80j/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/sony-xr-65a80j/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx (Google TV). Pass it to restore.sh as above;
# launcher/build-and-install.sh finds and disables it itself.
# Live TV / tuner app: com.sony.dtv.tvx (set it as live_tv_package in the launcher's config.xml and
#   hide it there; it also plays every HDMI input: HDMI 1-4 and AV show up in the Inputs menu).
# Keep (the TV needs them): com.sony.dtv.tvx, com.sony.dtv.tvinput.external and com.sony.dtv.tvinput.tuner
#   (both hold android.permission.TV_INPUT_HARDWARE: disable one and the ports still notice the cable but
#   stay black, with no way back short of a full restore and a cold boot, #321), com.sony.dtv.tvinput.hardwaremanager,
#   com.sony.dtv.tvinput.provider, com.sony.dtv.braviasync* (HDMI-CEC), com.sony.dtv.tvapi,
#   com.sony.dtv.sonysystemservice, com.sony.dtv.settingsprovider, all com.mediatek.* and mtktvapi.agent,
#   com.sony.dtv.recapp and recservice (recordings), reminderservice, timers, remotecontrolsettings,
#   irblaster/irbservice, com.sony.dtv.imeproxy, com.sony.dtv.webapi.core (Sony IP control),
#   com.sony.dtv.homenetwork (network standby / power settings), com.sony.dtv.ondservice,
#   preinappfiltering, b2b.rs232csupport, browser.webappservice.
# Kept by choice here, safe to add if you don't use them: Google Assistant (katniss, tv.assistant,
#   assistantadapter, voicesearch), Chromecast (apps.mediashell), the phone remote (tv.remote.service),
#   Sony firmware updates, Prime Video, Sony Media Player (smartmediaapp, osat.music),
#   Alexa/Google Home control (seeds.iot*, seeds.auth), Ambient mode (apps.tv.dreamx),
#   Living Decor (livingfit), Miracast service, text-to-speech (com.google.android.tts).
# Already disabled at the factory on this set: de.hdplus.tvapp.androidtv, com.sony.dtv.sonytab,
#   com.sony.dtv.b2b.vendorprotocol, com.sony.dtv.ardlauncher, com.sony.dtv.b2b.softap, com.netflix.ninja.
#   (Netflix is off: the owner turned it off before this list.) Not in this list, so restore.sh leaves them alone.
#
# Notes on this firmware, all checked on the TV:
# - Home: launcherx has priority 2 and the setup wizard's RecoveryActivity has priority 1, so setupwraith
#   is in this list (batch 6). With it disabled, build-and-install.sh set Home on the first try and it
#   survives reboots. Re-enable it before a factory reset (restore.sh does).
# - The saved Wi-Fi network belongs to android.uid.system, not to setupwraith, so disabling setupwraith
#   does not delete it. (dumpsys wifi: cname=android.uid.system:1000, SSID "T-R".) On a set where the
#   network was saved during first setup the script refuses to disable it and says so.
# - /data is small (16 GB storage). A launcher install can fail with "Requested internal only, but not
#   enough space"; `tools/tv.py 'pm trim-caches 1G'` frees a few hundred MB.
# - `svc power reboot` is killed on this firmware; use `adb reboot` (and check `uptime`).
# - The screensaver is com.google.android.apps.tv.dreamx/.service.Backdrop. The launcher's own
#   ClockDream can replace it (see the README).
# - Applied in batches with reboots and checks after each (Home, Settings, inputs, Media Player, no
#   crashes). If something breaks, `pm enable <package>` and please report it.
